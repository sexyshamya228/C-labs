Точка.
Создайте сущность Точка, которая описывается координатами X и Y.
Точка должна иметь текстовое представление в виде {X;Y}.

Поля класса:

public int X – координата по оси X
public int Y – координата по оси Y

Конструктор:

Point(int x, int y) – принимает координаты точки

Методы:

ToString() – возвращает строку в формате {X;Y}

Тесты

Точка 1
Введите X: 3
Введите Y: 5
{3;5}

Точка 2
Введите X: -2
Введите Y: 10
{-2;10}

Имя.

• только с личным именем
• с фамилией и именем

ToString() – возвращает строку ФИО без лишних пробелов

Введите отчество: Сергеевич

Введите имя: Клеопатра

Клеопатра

Линии.
Создайте сущность Линия, которая состоит из двух точек.
Реализовать возможность изменения координат точек и продемонстрировать работу ссылочного типа.

public Point Start – начальная точка

Конструктор:

Line(Point start, Point end)

Методы:

ToString() – возвращает строку
Линия от {x1;y1} до {x2;y2}

Тесты

Начальное состояние:
Линия от {1;2} до {3;4}

После изменения координат точки:
Линия от {10;20} до {3;4}

После создания новой точки и разрыва связи:
Линия от {5;5} до {3;4}

Города.
Создайте сущность Город, которая содержит:
• Название города
• Набор путей к другим городам (город + стоимость)

Город должен возвращать текстовое представление в виде
Название: Город:Стоимость

Поля класса:

public string Name – название города
public Dictionary<City, int> Roads – словарь дорог

Конструкторы:

City(string name) – создаёт город с пустым списком дорог
City(string name, Dictionary<City, int> roads) – создаёт город с заданными дорогами

Методы:

AddRoad(City city, int cost) – добавляет дорогу
ToString() – выводит город и список дорог

Тесты
Схема городов и путей

A: B:5 D:6 F:1

B: A:5 C:3

C: B:3 D:4

D: A:6 C:4

E: F:2

F: E:2

задача 5

Дроби.
Создайте сущность Дробь, которая:
• Хранит числитель и знаменатель
• Проверяет знаменатель ≠ 0
• Автоматически сокращает дробь
• Поддерживает операции сложения, вычитания, умножения, деления
• Поддерживает операции с целым числом

Поля класса:

public int Numerator – числитель
public int Denominator – знаменатель

Конструктор:

Fraction(int numerator, int denominator)

Методы:

Sum(Fraction other) – сложение дробей
Sum(int value) – сложение с целым
Minus(Fraction other) – вычитание дробей
Minus(int value) – вычитание целого
Multiply(Fraction other) – умножение
Divide(Fraction other) – деление
ToString() – возвращает строку в формате a/b

Тесты

Введите дробь f1
Числитель: 1
Знаменатель: 2

Введите дробь f2
Числитель: 1
Знаменатель: 3

1/2 + 1/3 = 5/6
1/2 - 1/3 = 1/6
1/2 * 1/3 = 1/6
1/2 / 1/3 = 3/2
1/2 - 2 = -3/2

Цепочка вызовов:
f1.Sum(f2).Divide(f3).Minus(5)
